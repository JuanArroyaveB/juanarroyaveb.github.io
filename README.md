# Academic website — Juan Carlos Arroyave

Trilingual academic website in English, Portuguese and Spanish, prepared for GitHub Pages.

## Main files

- `index.html` — home page.
- `teaching.html` — teaching page.
- `_data/` — personal content and translations.
- `_includes/` — page sections.
- `assets/fotos/` — profile photographs.
- `styles.css`, `theme.css`, `design.css` — visual design.
- `script.js` — language selection and photo rotation.

## Publish

Place the contents of this folder in the root of the `juanarroyaveb.github.io` repository, commit the changes and push them to the `main` branch. GitHub Pages will publish the site at `https://juanarroyaveb.github.io/`.
